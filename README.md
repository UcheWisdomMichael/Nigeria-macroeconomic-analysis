# Nigeria Macroeconomic Analysis (2008–2024)

## 📊 Project Overview
A Python-based data analytics project exploring Nigerian macroeconomic indicators from 2008 to 2024. This project investigates inflation trends, food price dynamics, and the historical relationship between consumer price indexes and crude oil prices using historical data.

---

## 🔍 Key Statistical Findings
* **Food CPI vs. Inflation Correlation ($0.896$):** Demonstrates a strong positive linear relationship, underscoring how heavily food price movements drive headline inflation trends in Nigeria.
* **Crude Oil Price Correlation ($-0.055$):** Reveals a surprisingly weak direct correlation with headline inflation over this timeframe, highlighting structural domestic factors influencing price stability.
* **Intra-Year Volatility Analysis:** Utilized Pandas `.agg()` functions to pinpoint specific historical spikes and economic extremes across multi-year cycles.

---

## 🛠️ Tech Stack & Methodology
* **Language:** Python
* **Libraries:** 
  * `pandas` & `numpy` for data cleaning, aggregation, and statistical testing.
  * `matplotlib` for multi-panel visualization design.
* **Techniques:** Missing value imputation, correlation matrices, multi-axis subplot structuring, and time-series aggregation.

---

## 📈 Visualizations
The analysis features a dual-panel dashboard comparing annual inflation trajectories alongside Food CPI trends from 2008 through 2024.
